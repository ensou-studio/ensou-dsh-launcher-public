## 四个不能混为一谈的边界

| 边界 | 必须证明的事项 |
| --- | --- |
| 登录身份 | 当前操作者控制了经验证的账号；登录成功本身不赋予使用资格。 |
| 管理员准入 | 管理员事先批准该账号参加内测，且批准当前未过期、未撤销。 |
| 设备授权 | 当前安装及设备属于该账号获准使用的设备，复制凭据不能换机使用。 |
| 模型 token | 模型供应商接受该调用凭据；它不是 Launcher 登录凭据或邀请资格。 |

Personal 台式机和笔记本必须分别登记、授权和验收，可以属于同一获准账号；不得直接套用企业单设备限制。具体设备上限需在实现和验收前明确。
Enterprise 保留现有企业微信身份验证、员工预登记、设备绑定与签名租约；客户企业独立管理员工准入和撤权。邀请制不将客户身份自动变成 Ensou 中央服务账号，也不互相信任任意企业签发的凭据。

## 强制行为

1. 未预确认账号即使完成自主注册、登录或取得下载链接，也不能自动获得 DSH 使用授权。
2. 服务器必须验证管理员准入、设备绑定和有效授权；客户端必须在启动及运行期执行相应校验。仅隐藏按钮、隐藏链接或由客户端自报获权不合格。
3. 授权请求及凭据必须防重放并绑定正确身份、设备和用途；不得将模型 token 用作通用登录或更新凭据。
4. 资格过期或撤销后，按已明确的授权有效期与刷新规则拒绝后续受管使用；需要停止运行时，只停止本产品拥有的进程。
5. 拒绝、过期、撤销及安全凭据清理均不得删除聊天与工作区；不得用“重新安装并清空数据”作为常规解法。
6. 必要的安全更新、故障恢复入口应独立保留最小权限并继续验证签名和防回滚状态；不得借恢复入口绕过使用准入、启动模型调用或接受未签名程序。
7. 首次授权不得离线完成。已有授权只能在验证通过的有限有效期及明确离线策略内使用；无法验证、超期或检测到时间异常时拒绝受管使用，不跳过校验。
8. 离线设备不能承诺即时收到服务器撤销；发布前必须确定并实测最长离线授权窗口，不得声称“即时全设备撤权”。恢复联网后先同步授权状态再继续使用。
9. Launcher 撤权不能保证已交给用户的第三方模型 token 同时失效或无法在其他工具使用。发放方须另行撤销或轮换模型凭据，并验证供应商实际拒绝。
10. 登录不替代接口授权、限流及网络防护；日志和验收证据不得包含 token、授权正文、聊天内容或工作区内容。
