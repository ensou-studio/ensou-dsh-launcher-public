# Ensou DSH Personal 小范围试用指南

本文面向收到正式试用邀请的个人用户与家人。它不要求安装 Git、FNM 或 Node.js，也不要求使用命令行。

## 目前的状态

**当前还没有可下载的正式试用包。** 更新服务上线、签名候选和发行信任仍须完成验收；请不要从聊天记录、临时测试目录或其他非官方位置取得安装文件。

本次为邀请制内测：只有管理员事先确认的人员才能获得使用授权。Personal 的预登记邮箱验证码、管理员批准/撤销、设备证明、Launcher 启动与运行期账号门禁已在客户端和服务端源码中实现；但真实 SMTP、Windows CNG、PostgreSQL、HTTPS、正式账号地址和逐台命名设备准入尚未完成端到端验收，因此当前仍不能下载、登录或开放内测。收到安装包、注册账号或持有模型 token，都不能代替管理员批准。当前边界和待验收项见 [邀请制内测准入验收](private-pilot-access.zh-CN.md)。

收到邀请后，您将获得一个经过签名的 Windows 安装包和官方获取方式。请只从该方式下载；不要关闭 Windows 的安全提示，也不要按他人建议绕过 SmartScreen 或其他系统保护。

## 安装和首次使用

以下是现有邮箱验证码方案完成真实部署与验收后应提供的使用流程。邮箱验证码已经选定并接入源码，不表示当前已有可用的正式账号服务、登录入口或下载包；扫码和手机号不是本次 Personal 内测首发方式。

1. 先由管理员确认您的试用资格，再通过正式方式获取安装包并安装。
2. 从开始菜单或桌面启动 Ensou DSH Launcher，完成身份登录和本台设备授权；台式机与笔记本分别授权。
3. 准入通过后进入本机 DSH 页面，阅读内测声明并按提示继续；未获批准时应明确拒绝使用，不能因自行注册而自动获权。
4. 配置模型 API Key。如果管理员提供的是与页面匹配的 API Key，请在 Launcher 打开的本机 DSH 页面中填写；否则先选择“稍后配置”，让管理员确认凭据类型和填写位置，不要把设备绑定码或登录凭据填入 API Key 栏。

每个人使用自己的 token。凭据由管理员通过约定的私密方式单独发放；收到后不要转发到群聊、支持对话、截图、工单或共享文档中，也不要把它写入安装包、快捷方式或工作区文件。需要补发或更换 token 时，请联系发放试用邀请的管理员。

取得使用和设备授权后，没有配置模型凭据时可以进入配置引导；模型功能仍需要匹配且有效的凭据。发布前须使用实际发放的凭据完成真实模型调用验收，本机引导界面测试不能替代这一项。撤销 Launcher 使用授权不等于模型供应商已撤销 API Key，后者须由发放方单独处理。

## 您的文件与更新

- 工作区和聊天数据保留在本机。不要为了更新而手动删除或移动工作区。
- Launcher 与 DSH 运行时可以分别更新。这是预期设计：请让 Launcher 按提示完成更新，不要自行替换程序文件或从其他来源复制 EXE。
- 更新过程中请保持电脑接通电源和网络；如果提示失败或回退，请记录提示内容并联系管理员，而不是反复运行未知安装包。
- 未授权、授权过期或撤销不得删除聊天与工作区。必要的安全更新和恢复入口应保留，并继续验证签名；这不等于恢复 DSH 或模型使用资格。
- 离线不能取得首次授权。已授权设备也不得无限离线使用，必须遵守已验收的有效期和离线规则；无法确认资格时请联网或联系管理员，不要修改电脑时间。

## 需要帮助时

请提供以下不含敏感信息的内容：

- 您看到的错误提示文字和发生时间；
- Launcher 显示的版本与更新频道；
- 不含 token、API Key、个人文件路径、聊天内容或工作区内容的错误截图。

不要发送 token、`launcher.settings.json`、个人 `.dsh` 目录、完整日志压缩包，或任何包含聊天/工作区内容的文件。管理员如确实需要诊断材料，会提供专门的安全收集方式。

## 试用验收范围

本指南方便日常使用，但不替代发行验收。首个小范围 Pilot 仍需在 PILOT-DESKTOP 台式机和 PilotNotebook 笔记本上，对同一个不可变候选完成 16 项真实设备检查，包括首次安装/已有安装升级、Launcher-only 与 Runtime-only 更新、失败回退、离线可用性、本地数据保持和无命令窗口。

工程验收要求和证据格式见 [Personal 双设备 Pilot 验收](personal-dual-device-pilot.md)。只有该验收、[邀请制准入验收](private-pilot-access.zh-CN.md)、正式签名和更新地址配置都完成后，才会开放实际下载。
